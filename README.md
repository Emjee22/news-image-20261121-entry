# Saturday 21 November 2026 — The World in One Day

A newspaper front page summing up Saturday 21 November 2026 in one image:
31 verified stories across 6 regions, led by Russia's overnight strike on
Kyiv with missiles landing in Poland, the COP31 climate summit running into
overtime in Antalya, and the magnitude 6.7 earthquake in central Peru.

Drawn entirely by `main.py` (Python 3.13, standard library only): a
hand-defined 5x7 bitmap font, flat shapes, and a pure-Python PNG encoder.
No network, no external files, deterministic — two runs write identical bytes.
